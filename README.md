# PvP Verse Rank Store

Static PvP Verse storefront backed by Supabase.

Server: pvpverse.softhost.fun
Discord: https://discord.gg/pvp-verse-1502221994765189130

The browser uses the Supabase publishable key. Orders are inserted as pending and must be paid/verified server-side before rank fulfillment. The Minecraft side is intended to use the custom rank plugin, not LuckPerms.
